# iMow 新标签页

一个简洁、可高度自定义的浏览器新标签页扩展（Manifest V3）。打开新标签页即可搜索、访问常用网站，并按自己的习惯调整壁纸、布局、图标与搜索框。

- Edge 扩展商店：<https://microsoftedge.microsoft.com/addons/detail/imow%E6%96%B0%E6%A0%87%E7%AD%BE%E9%A1%B5/aihjofmgjbjgafacflekdpnglmaiinnp>
- 当前版本：**1.0.1**
- 版本发布记录：<https://github.com/Arlo511/iMow-newtab/releases>

## 主要功能

### 搜索
- 内置必应、百度、谷歌、Yandex、搜狗、360 搜索，可在搜索框左侧下拉切换。
- 支持新增、编辑、删除自定义搜索引擎，地址中用 `{}` 表示关键词占位。
- 可选择搜索结果在当前标签页或新标签页打开。
- 搜索框宽度、高度、圆角、透明度、背景模糊、上下位置均可调。

### 网站快捷方式
- 添加、编辑、删除网站，支持自定义名称、网址与图标。
- 图标可手动填写 URL、上传本地图片，或根据网址自动抓取（优先站点声明的图标与同源 favicon，其次 Google / DuckDuckGo / Yandex 图标服务）。
- 每个网站可单独设置图标大小（20%–200%）、图标底色，或设为透明。
- 「一键适配」可通过 canvas 读取图标边缘像素的主色并自动作为底色；整图透明时回退为透明底色。
- 支持每页 2×5 / 2×6 / 2×7 / 2×8 / 3×5 / 3×6 / 3×7 预设，或自定义 1–5 行 × 3–8 列。
- 图标间距、整体上下位置、名称显隐、名称字号与颜色均可调。

### 翻页
- 网站超过一页时，可用鼠标滚轮、方向键（←/→/↑/↓）或底部分页点切换。
- 四种翻页动画：水平滑动、交叉淡入、上下堆叠、无动画；动画只作用于 transform 与 opacity，并严格串行播放，避免两页图标同屏。

### 壁纸
- 默认使用必应每日壁纸的 4K 超清版本（3840×2160）；旧的 1920 低清缓存会在启动时静默升级，升级失败保留原壁纸。
- 内置多个随机壁纸源，支持切换、编辑与新增自定义 API 地址。
- 支持上传本地图片作为壁纸、移除背景，以及下载当前壁纸。

### 数据管理
- 支持将全部设置与网站数据导出为 JSON 备份，也可从备份文件导入。
- 支持一键恢复默认设置。

## 安装与使用

### 从商店安装（推荐）

打开上方 Edge 扩展商店链接，点击「获取」安装。

### 手动加载（开发/测试）

1. 从 [Releases](https://github.com/Arlo511/iMow-newtab/releases) 下载最新版本的 zip 并解压。
2. 打开 `edge://extensions`（Chrome 为 `chrome://extensions`），开启「开发人员模式」。
3. 点击「加载解压缩的扩展」，选择解压后的目录（该目录下应直接看到 `manifest.json`）。
4. 新建标签页即可使用。

### 使用提示

- 点击右上角齿轮打开设置；「网站图标」分组中的「+ 添加网站」用于新增快捷方式。
- 鼠标悬停在网站图标上会显示编辑与删除按钮。
- 在设置中选择壁纸源后，可点击缩略图区域的下载按钮保存当前壁纸。

## 目录结构

```text
.
├── manifest.json                 # 扩展清单（Manifest V3，newtab 覆盖）
├── index.html                    # 新标签页与设置面板
├── script.js                     # 数据、搜索、网站、壁纸、动画等全部逻辑
├── styles.css                    # 页面与设置面板样式
├── early-bg.js                   # 首帧应用缓存壁纸，减少刷新闪屏
├── icons/
│   ├── icon_32.png               # 扩展图标 32×32
│   ├── icon_48.png               # 扩展图标 48×48
│   ├── icon_128.png              # 扩展图标 128×128
│   ├── cat-icons/                # 右下角猫咪按钮素材
│   ├── search-engines/           # 内置搜索引擎图标
│   └── websites-icons/           # 默认网站图标
├── wallpapers/
│   └── default.png               # 内置默认壁纸
└── .gitignore
```

## 权限说明

| 权限 | 用途 |
| --- | --- |
| `storage` / `unlimitedStorage` | 在浏览器本地保存设置、网站列表与壁纸缓存 |
| `downloads` | 仅在用户点击「下载壁纸」时保存当前壁纸 |
| `host_permissions`（`https://*/*`、`http://*/*` 及内置服务域名） | 读取用户输入的网址首页以获取标题与图标信息、下载并校验图标、获取所选壁纸源的图片 |

> `manifest.json` 中的 `activeTab` 为早期版本遗留声明，当前版本未调用，计划在后续版本移除。

## 隐私说明

- **数据只存本地**：网站、搜索引擎、设置与壁纸缓存均保存在浏览器 `localStorage` 中，不同步、不上传到任何服务器。
- **无账号、无统计、无追踪**：扩展不收集个人信息，不包含分析或广告代码。
- **网络请求仅用于功能本身**：只有在打开新标签页、切换/刷新壁纸、自动抓取网站信息或图标、下载远程图标时，才会访问对应网址或内置服务；请求结果仅用于页面展示与本地缓存。
- **导出备份**由用户在本地主动触发，文件只保存在用户选择的路径。
